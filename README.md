## Principais comandos Git e suas funções

### git init
Inicia um novo repositório Git na pasta atual.

### git status
Mostra o estado atual dos arquivos e informa quais foram alterados.

### git add .
Adiciona todas as alterações para a área de preparação.

### git add nome-do-arquivo
Adiciona apenas um arquivo específico para a área de preparação.

### git commit -m "mensagem"
Registra uma nova versão do projeto com uma mensagem explicando a alteração.

### git log
Mostra o histórico de commits realizados.

### git clone URL
Faz uma cópia de um repositório remoto para o computador.

### git pull
Baixa e integra as alterações do repositório remoto.

### git push
Envia os commits feitos no computador para o GitHub.

### git branch
Mostra as branches existentes no projeto.

### git switch nome-da-branch
Troca de uma branch para outra.

### git switch -c nova-branch
Cria uma nova branch e muda para ela.

### git merge nome-da-branch
Une as alterações de uma branch com a branch atual.

### git diff
Mostra as diferenças feitas nos arquivos.

### git fetch
Baixa informações do repositório remoto sem integrar automaticamente.

### git restore nome-do-arquivo
Desfaz alterações feitas em um arquivo que ainda não foram salvas em commit.

### git stash
Guarda temporariamente alterações que ainda não foram commitadas.

## GitHub

O GitHub é uma plataforma utilizada para armazenar repositórios Git na internet.

Ele permite:

- Compartilhar projetos;
- Trabalhar em equipe;
- Armazenar código;
- Acompanhar alterações;
- Criar Pull Requests;
- Registrar Issues;
- Organizar projetos de programação.

## Diferença entre Git e GitHub

**Git:** é o sistema de controle de versão usado no computador.

**GitHub:** é uma plataforma on-line usada para armazenar e compartilhar repositórios Git.

## Conclusão

Git e GitHub são ferramentas importantes para o desenvolvimento de software. O Git ajuda a controlar as versões e alterações de um projeto, enquanto o GitHub facilita o armazenamento e o trabalho colaborativo.
